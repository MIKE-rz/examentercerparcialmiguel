### Parte 1. Actividades y clases
- Desarrollo de ejercicios de programación en Python.
- Uso de clases, atributos, métodos y objetos.
- Implementación de una clase Rectangulo para calcular áreas.

### Parte 2. Cobro de estacionamiento
- Creación de la clase Estacionamiento.
- Cálculo del pago dependiendo de las horas estacionadas.
- Validación de datos ingresados por el usuario.
- Generación de recibo de estacionamiento.

### Parte 3. Calculadora con herencia
- Creación de la clase Operacion como clase padre.
- Creación de la clase Resta como clase hija.
- Implementación de herencia y redefinición de métodos.
- Cálculo de suma y resta de dos números.
